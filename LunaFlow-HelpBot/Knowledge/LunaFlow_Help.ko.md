# LunaFlow 사용 도우미 지식 문서

이 문서는 LunaFlow 편집기 안의 **LunaFlow 도우미**가 내장 도움말로 사용하고,
Copilot Studio 도우미 에이전트에 지식(Knowledge) 파일로 업로드하는 사용 설명서다.
각 `##` 절이 하나의 주제이며 `키워드:` 줄은 내장 도움말 검색에 쓰인다.

## 시작하기 {#start}
키워드: 시작, 실행, 처음, 설치, 빌드, 켜는, 열기, start, launch, run, install, build, getting started

- **데모 ZIP:** 압축을 풀고 `LunaFlow.exe`를 실행한다. .NET·Visual C++ 설치나 Microsoft 로그인이 필요 없다(Windows 10/11 x64, 인터넷 연결 필요).
- **실행(소스):** LunaFlow 폴더의 `Start-LunaFlow.cmd`를 더블클릭한다. 실행 파일은 `build/Release/LunaFlow.exe`다.
- **처음 빌드:** Visual Studio 2022(C++ 데스크톱 개발, Windows SDK, CMake)가 필요하다. 루트에서 `.\Build-LunaFlow.ps1 -Configuration Release -Test`를 실행한다.
- **Visual Studio로 열기:** `Open-LunaFlow.cmd`를 실행하면 솔루션을 현재 경로로 다시 구성한 뒤 연다.
- 시작하면 기본 캐릭터(`Chracter Modeling 1.fbx`의 사본)를 열고 자동 리깅을 적용해 바로 동작을 만들 수 있다.
- 처음이라면 이 순서를 추천한다: 우클릭 드래그로 시점 돌리기 → 뼈 클릭 후 E(회전)로 포즈 잡기 → K로 키 추가 → Space로 재생 → Ctrl+S로 저장.

## 화면 구성과 작업 탭 {#workspace}
키워드: 화면 구성, 작업 탭, 레이아웃, 패널, 계층, 인스펙터, 속성 창, 상태 줄, 작업 공간, workspace, layout, panel, hierarchy, inspector, tab

- **상단:** 파일·편집·보기·설정·도움말 메뉴, `+`(장면에 오브젝트·VFX 추가), 애니메이션·장면·VFX 작업 탭.
- **왼쪽:** 계층(화살표로 펼치기/접기), 동작 목록, 자산 정보, 효과 목록 탭. 작업 탭과 별도로 전환할 수 있다.
- **가운데:** 3D 뷰포트(이동·회전·크기 핸들, 오른쪽 위 축 기즈모)와 아래쪽 타임라인.
- **오른쪽:** 선택 대상의 속성과 AI 대화.
- **하단 상태 줄:** 저장 상태, 진행 안내, 실제 FPS, **도우미** 버튼.
- 작업 탭: **애니메이션**은 동작 목록과 뼈 키 편집, **장면**은 계층과 오브젝트 배치, **VFX**는 효과 목록·효과 속성·VFX AI를 연다.
- 바깥 화면은 고정이고 계층·속성·대화 기록 같은 패널 안에서만 스크롤된다.

## 뷰포트 카메라 조작 {#camera}
키워드: 카메라, 시점, 뷰포트, 화면 이동, 확대, 축소, 줌, 비행, wasd, 회전시키, 돌리, 직교, 원근, 축 기즈모, 맞추기, camera, viewport, orbit, pan, zoom, fly, navigation, frame

Unity·Blender 방식이다.

- **시점 회전:** 우클릭 드래그 또는 Alt + 좌클릭 드래그.
- **화면 이동(팬):** 가운데(휠) 버튼 드래그, 또는 빈 공간 좌클릭 드래그.
- **확대·축소:** 마우스 휠 또는 Alt + 우클릭 드래그.
- **비행 이동:** 우클릭을 누른 채 W/A/S/D(앞·왼쪽·뒤·오른쪽), Q/E(아래·위). Shift는 빠르게, 이동 중 휠은 이동 속도 변경. 우클릭을 누르고 있지 않으면 W/E/R은 변환 도구 전환이다.
- **맞추기:** F 또는 숫자패드 . = 선택 항목에 맞추기, Shift+F = 전체 보기.
- **축 보기:** 숫자패드 1·3·7 = 정면·우측·상단, Ctrl을 함께 누르면 반대쪽, 9 = 반대편, 5 = 원근/직교 전환, 2·4·6·8 = 15°씩 회전.
- **축 기즈모(오른쪽 위):** 축을 클릭하면 그 방향 보기(다시 클릭하면 반대편), 드래그하면 시점 회전, 글자를 클릭하면 원근/직교 전환.
- 시점 회전이나 회전 링을 드래그하다 커서가 모니터 가장자리에 닿으면 반대편으로 넘어가 계속 돌릴 수 있다.

## 단축키 모음 {#shortcuts}
키워드: 단축키, 키보드, 핫키, f1, ctrl, shortcut, shortcuts, hotkey, keyboard, keymap

**F1** 또는 `도움말 > 단축키 보기`에서 전체 목록을 연다. **Shift+F1**은 이 도우미 창을 열고 닫는다.

- **파일:** Ctrl+S 저장, Ctrl+Shift+S 다른 이름으로 저장, Ctrl+O 열기.
- **편집:** Ctrl+Z 실행 취소, Ctrl+Y 또는 Ctrl+Shift+Z 다시 실행, Ctrl+D 동작·효과 복제, Delete 선택한 키·효과 삭제, Esc 키 선택 해제.
- **도구:** W 이동, E 회전, R 크기, X 월드/로컬 기준 전환, 조작 중 Ctrl은 눈금 스냅(0.1m / 15° / 0.1).
- **타임라인:** Space 재생/정지, 좌우 화살표(또는 , .) 한 프레임, 위/아래 화살표(Alt+. / Alt+,) 다음·이전 키, Home/End 처음·마지막, K 또는 I 키 추가.
- **뷰포트:** 우클릭 + WASDQE 비행, F 맞추기, Shift+F 전체, 숫자패드 1/3/7/9/5.
- **모션캡처 중:** Space 녹화 시작·정지, Esc 카운트다운 취소, Enter 테이크 완료, Delete 테이크 버리기.
- 글자 입력 칸에 커서가 있으면 단축키 대신 글자가 입력된다.

## 선택과 이동·회전·크기 조절 {#transform}
키워드: 선택, 이동, 회전, 크기, 스케일, 핸들, 기즈모, 뼈 선택, 스냅, 로컬, 월드, select, move, rotate, scale, gizmo, handle, snap, transform

- 뷰포트에서 오브젝트·뼈를 좌클릭하면 선택된다. 계층에서 골라도 된다.
- W/E/R로 이동·회전·크기 도구를 바꾸고, 선택 대상을 좌클릭 드래그하거나 핸들을 드래그한다.
- X는 월드/로컬 기준 전환, 드래그 중 Ctrl을 누르면 0.1m / 15° / 0.1 단위로 스냅한다.
- 회전 링을 드래그하다 화면 가장자리에 닿으면 커서가 반대편으로 넘어가 계속 회전한다(Unity와 같은 동작).
- **장면 탭**에서는 오브젝트 단위로 배치하며 모든 동작에 유지된다. **애니메이션 탭**에서 뼈를 조작하면 선택한 동작의 현재 시각에 키가 기록된다.
- 속성 창의 숫자를 드래그해도 값을 바꿀 수 있고, 더블클릭하면 직접 입력한다.

## 캐릭터 불러오기와 소품(검) 부착 {#character}
키워드: 캐릭터, fbx, 모델, 불러오기, 가져오기, 임포트, 소품, 부착, 붙이, 무기, 손에, character, import, model, prop, attach, weapon, gltf, obj

왼쪽 위 **FBX 가져오기** 또는 `파일 > FBX 가져오기`에서 고른다.

- **캐릭터 열기:** 현재 장면을 저장할지 확인한 뒤 캐릭터와 포함된 동작을 연다.
- **현재 장면에 모델 추가:** 캐릭터를 유지하고 검 같은 소품을 추가한다.
- **동작만 가져오기 · 체형 보정:** FBX의 동작을 현재 캐릭터에 맞춘 새 클립으로 만든다(손발 IK, 보폭 보정, 15/30/60 FPS).
- FBX·glTF·GLB·OBJ를 읽는다. 뼈대가 없는 사람형 모델이면 자동 리깅을 안내한다.

**검을 손에 붙이는 법**
1. `+ > 모델 / 소품 가져오기`로 검 모델을 추가한다.
2. 계층에서 검의 최상위 오브젝트를 선택한다.
3. 속성의 **오브젝트 부착**에서 RightHand 같은 뼈를 고르고 `선택한 뼈에 부착`을 누른다.
4. 핸들이나 숫자로 검의 위치·방향·크기를 맞춘다. 이후 검은 손을 따라 움직인다.

`+`에서 큐브·구·원기둥·원뿔·평면·토러스 도형도 추가할 수 있다.

## 자동 리깅 {#autorig}
키워드: 자동 리깅, 리깅, 뼈대 없, 뼈가 없, 스킨, 가중치, 웨이트, 본 생성, auto rig, autorig, rigging, skeleton, skin weights

- 뼈대가 없는 사람형 메시를 열면 **FBX 가져오기** 아래에 안내와 **자동 리깅** 버튼이 나온다. `편집 > 캐릭터 자동 리깅`으로도 실행한다.
- 메시를 분석해 Hips·Spine·Chest·Neck·Head, 양쪽 Shoulder·UpperArm·ForeArm·Hand, UpperLeg·LowerLeg·Foot·Toes 등 **26개 뼈**와 스킨 가중치를 만든다. Unity 사람형 이름을 써서 AI 동작·FBX 동작 보정·Unity 내보내기에 그대로 쓸 수 있다.
- 발끝 방향으로 정면을 정하므로 모델이 어느 쪽을 보고 있어도 된다. 긴 옷·로브도 지원한다.
- 서 있는 T·A 자세가 가장 정확하다. 팔을 내린 I 자세는 신체 비율로 관절을 추정하고 정보 탭에 안내를 남긴다.
- 결과는 Ctrl+Z로 되돌리고 Ctrl+Y로 다시 적용한다.
- 상자·기둥 같은 비인체 메시나 누워 있는 모델은 바꾸지 않고 이유를 표시한다. 손가락·얼굴·옷자락 뼈는 만들지 않는다.

## 동작 클립과 키프레임 {#keyframes}
키워드: 동작, 클립, 키프레임, 키 추가, 키 삭제, 타임라인, 재생, 애니메이션 만들, 포즈, 길이, 반복, 복제, keyframe, key, timeline, clip, motion, animation, playback, loop

- 왼쪽 **동작** 탭에서 새 동작 만들기·선택·이름 변경·복제(Ctrl+D)·삭제·길이 변경을 한다. 길이를 바꾸면 모든 키 시간이 함께 늘거나 준다.
- **키 만들기:** 타임라인에서 시각을 고르고 뼈를 선택해 회전/이동하면 그 시각에 키가 생긴다. K 또는 I로 현재 포즈를 키로 추가한다.
- **키 편집:** 키 다이아몬드를 클릭해 선택, 더블클릭 또는 `선택 키 편집`으로 시간을 바꾸거나 삭제한다. Delete로 삭제, Esc로 선택 해제.
- **이동:** 좌우 화살표 한 프레임, 위/아래 화살표 다음·이전 키, Home/End 처음·끝, Space 재생/정지, 반복 버튼.
- 모든 편집은 Ctrl+Z / Ctrl+Y로 되돌리고 다시 실행한다.

## 검 휘두르기 동작 만들기 {#sword}
키워드: 검 휘두, 검을, 검으로, 칼, 베기, 베는, 휘두르, 공격 동작, 검술, sword, slash, swing, attack

가장 쉬운 방법은 오른쪽 **AI 대화**에 `오른손으로 검을 휘두르는 동작 만들어 줘`처럼 요청하는 것이다.

- AI는 전신 베기 프리셋(create_sword_swing)을 사용한다. 가드 → 와인드업(몸통을 감고 검을 머리 위로) → 앞발을 내딛으며 골반을 낮추고 몸 앞 아래로 베기 → 회복 → 가드 순서다.
- 골반·척추·목(시선 유지)·쇄골·양팔·양다리를 함께 움직이고, 뒷발은 IK로 바닥에 고정한다. 손은 항상 캐릭터의 실제 정면을 지난다.
- 왼손으로 하려면 `왼손으로`라고 말한다. 길이는 `1.2초짜리`처럼 지정한다(0.2~30초).
- 결과는 새 동작으로 만들어지고 기존 동작은 바뀌지 않는다. Ctrl+Z 한 번으로 이번 AI 작업 전체를 되돌린다.
- 검 모델을 손에 붙이려면 "캐릭터 불러오기와 소품(검) 부착" 주제를 참고한다.
- 뼈대가 없는 캐릭터라면 먼저 `편집 > 캐릭터 자동 리깅`을 실행한다.

## AI 대화로 동작 편집하기 {#ai-chat}
키워드: ai 대화, 채팅, 코파일럿, copilot, 프롬프트, 명령, 요청, 자연어, ai로, 에이전트, 편집 계획, ai chat, agent, prompt, natural language

오른쪽 **AI · Copilot Studio** 대화창에 문장으로 동작·효과 편집을 요청한다.

- 예: `선택한 동작을 복제해서 1.5초로 줄이고, 복제한 동작의 오른손에 파란 불꽃을 붙여 재생해 줘.`
- 지원: 새 동작, 검 휘두르기, 복제·이름 변경·길이 변경·반복, 뼈 키 설정/회전/방향 맞추기, 파티클 생성·수정·부착, 결과 재생.
- 기다리는 동안 반짝이는 **생각 중…** 글자, 경과 시간, 현재 단계가 보인다. 계획이 오면 전체를 미리 검증한 뒤 `편집 적용 중 k/N`으로 단계별 적용한다.
- **작업 중지**로 멈추고, 적용된 AI 작업은 **Ctrl+Z 한 번**으로 모두 되돌린다.
- 기다리는 동안 직접 뼈·동작·효과를 고치면 오래된 결과는 적용하지 않는다. 새 상태로 다시 요청한다.
- 배포판(데모 ZIP)은 로그인 없이 바로 쓴다. 로그인 모드로 구성한 경우에만 첫 요청 때 브라우저에서 Microsoft 계정으로 로그인한다. 연결 설정은 "Copilot Studio 연결 설정" 주제를 본다.
- 문장이 JSON 편집 계획으로 바뀌는 원리는 `LunaFlow/Docs/Sentence_to_JSON.ko.md` 문서에 정리되어 있다.

## VFX 효과 만들기와 속성 {#vfx}
키워드: vfx, 이펙트, 효과, 파티클, 입자, 불꽃, 연기, 마법, 눈송이, 빗방울, 폭발, 칼 궤적, 트레일, 스파크, 오라, particle, effect, fire, smoke, magic, trail, aura

상단 **VFX** 작업 탭을 연다.

- **새 효과 갤러리(왼쪽 아래):** 파티클·불꽃·연기·마법·눈·비·폭발·칼 궤적·스파크·오라를 한 번 누르면 `부착 위치`의 뼈에 추가된다. `+ > 파티클 시스템`도 가능하다.
- **효과 목록(왼쪽):** 체크박스로 켜고 끄기, 더블클릭으로 뷰포트 이동, 우클릭으로 복제·삭제.
- **효과 속성(오른쪽):** 활성화·재생 → 부착·재생 구간 → 기본 → 방출 → 모양(원뿔/구/상자/고리) → 추가 속도 → 시간에 따른 색상·크기 → 렌더러 순서. 부착 뼈는 검색해서 고르고, 색상은 견본을 눌러 선택한다.
- 효과는 선택한 동작과 뼈에 연결되어 동작 시간 안에서 재생된다. 같은 시드·시간이면 같은 입자 상태가 재현된다.
- 칼 궤적은 부착점에서 로컬 +Y 방향으로 뻗는 날의 움직임을 기록하므로 검 방향에 맞게 오프셋·방향·크기를 조절한다.
- 모든 효과 편집은 Ctrl+Z로 되돌리고 프로젝트에 저장된다.

## VFX AI로 효과 만들기 {#vfx-ai}
키워드: vfx ai, 효과 ai, 파티클 ai, 로컬 모드, 키워드 규칙, 초당, 수명, 효과 만들어, vfx agent, local rules

VFX 탭 오른쪽 아래 **VFX AI**에서 문장으로 효과를 만든다.

- **로컬:** 로그인 없이 한국어/영어 키워드와 숫자를 해석한다. 예: `파란 마법 파티클, 초당 80개, 수명 1.5초, 크기 0.12, 반경 0.3`, `RED explosion particles burst 250 lifetime 1.8 speed 4 once`.
- 로컬 키워드: 불꽃/fire, 연기/smoke, 마법/magic, 눈송이/snow, 빗방울/rain, 폭발/explosion, 파티클/particle, 색(빨간·파란·보라·초록·노란·하얀·분홍), 느리게/빠르게, 풍성하게, 구형/원뿔/상자/고리, 한 번/반복, 월드. 숫자: 초당·수명·속도·크기·반경·퍼짐·방출·한번에.
- **Copilot:** 전용 VFX 에이전트가 장면을 보고 파티클 생성·기존 효과 수정·부착·미리보기 계획을 만든다. `선택한 효과의 입자 크기를 절반으로 줄여 줘` 같은 후속 수정도 된다.
- 예시 버튼을 누르면 입력이 채워지고 Ctrl+Enter로 보낸다. 머리글의 ▼로 숨기고 `VFX AI 열기`로 다시 연다.
- 지원하지 않는 표현이나 범위를 벗어난 수치는 오류를 보여 주고 기존 효과를 바꾸지 않는다.

## 웹캠 모션캡처 {#mocap}
키워드: 모션캡처, 모션 캡처, 웹캠, 카메라로, 녹화, 캡처, 미디어파이프, mocap, motion capture, webcam, record, mediapipe

타임라인 맨 왼쪽의 빨간 **녹화(●)** 버튼이나 `보기 > 웹캠 모션캡처...`를 누른다.

1. 패널이 열리며 카메라가 켜진다. 처음이면 **설치하고 카메라 켜기** 한 번으로 Python 전용 환경과 MediaPipe 모델이 설치된다(Python 3.11 x64 필요).
2. 밝은 곳에서 머리부터 발끝까지 보이게 서서 팔을 내리고 잠깐 멈추면 기준 자세가 자동으로 잡힌다.
3. **녹화** 또는 Space → 카운트다운(기본 3초) → 녹화(뷰포트 빨간 테두리와 REC 시간) → **정지** 또는 Space.
4. 테이크는 즉시 새 동작으로 캐릭터에 적용되어 반복 재생된다. **계속 녹화(Space) / 버리기(Delete) / 완료(Enter)**, 시작·끝 트림을 고른다.
5. 키는 1° 오차로 자동 정리된다. 잘못 잡힌 키는 타임라인에서 지우고, 테이크마다 Ctrl+Z, 저장은 Ctrl+S.

- 카메라가 켜진 동안 메뉴·편집·AI 작업은 잠기지만 뷰포트 시점 조작은 된다.
- 정면·제자리 1인 전신 동작용이다. 손가락·표정·발 고정·공간 이동은 기록하지 않는다. 영상은 저장하거나 외부로 보내지 않는다.

## Unity로 가져가기 {#unity}
키워드: 유니티, unity, 프리팹, 패키지 매니저, 애니메이터, 게임 엔진, prefab, package manager, animator

방법은 두 가지다.

**A. `.lunaflow` 파일 직접 가져오기(추천)**
1. Unity 6에서 `Window > Package Management > Package Manager`를 연다.
2. `+ > Install package from disk`로 `LunaFlow-Unity/package.json`을 고른다.
3. LunaFlow에서 Ctrl+S로 저장한 `.lunaflow` 파일을 Unity의 `Assets` 폴더에 넣는다.
4. 가져온 에셋을 Hierarchy에 드래그하고 Play를 누르면 동작과 VFX가 재생된다. `LunaFlowPlayer`에서 다른 동작을 고른다.
5. 원본을 고치면 자동으로 다시 가져온다. 직접 수정할 프리팹은 Prefab Variant로 만든다.

**B. FBX + 메타데이터 내보내기**
`파일 > 내보내기 > Unity 패키지`로 Unity 프로젝트의 `Assets/LunaFlow` 폴더에 저장하면 스크립트가 여러 동작, Animator Controller, 프리팹을 구성한다.

- 애니메이션은 Generic 리그다. Humanoid 리타기팅은 하지 않는다.
- 파티클은 Unity 기본 ParticleSystem으로 변환된다. 외형은 엔진 차이로 완전히 같지는 않다.

## Copilot Studio 연결 설정 {#copilot-setup}
키워드: 연결 설정, 로그인, 로그인 없이, 설정 파일, settings.local.json, settings.public.json, 에이전트 연결, 연결 안, 인증, 인증 안 함, 게시, setup, sign in, login, no authentication, configure, publish, environment id, schema name

LunaFlow는 세 개의 Copilot Studio 에이전트를 각자의 설정 파일로 연결한다. 기능 폴더에 `settings.public.json`이 있으면 그것을 먼저 쓰고, 없으면 `settings.local.json`을 쓴다.

| 기능 | 폴더 | 안내 |
|---|---|---|
| 애니메이션 AI 대화 | `agent_service/copilot_client/` | `LunaFlow/Docs/Copilot_Studio_Setup.ko.md` |
| VFX AI | `LunaFlow-VFXAgent/` | `LunaFlow-VFXAgent/SETUP.ko.md` |
| LunaFlow 도우미 | `LunaFlow-HelpBot/` | `LunaFlow-HelpBot/SETUP.ko.md` |

**로그인 없이 쓰기 (`settings.public.json`, 배포판 기본값)**
- Copilot Studio에서 에이전트마다 설정 → 보안 → 인증 → **인증 안 함** → 저장 → **게시**한다.
- 파일 내용은 `{"Authentication":"None","EnvironmentId":"<GUID>","SchemaName":"<스키마 이름>"}`이다. 프로그램을 실행하면 로그인 창 없이 바로 연결된다.
- 오류에 "인증 안 함 … 다시 게시"가 보이면 그 에이전트가 아직 인증을 요구하는 상태다. 조직 DLP 정책이 인증 없는 에이전트를 막을 수도 있다.
- 인증을 꺼도 404가 계속되면 제작자가 `Set-DemoSecrets.ps1`로 웹 채널 보안 암호를 `directline.secret`에 넣고 ZIP을 다시 만든다. 이 파일은 GitHub에 올라가지 않는다. "Direct Line 암호가 거부되었습니다"는 암호가 다시 생성된 것이므로 새 ZIP을 받는다.
- `settings.public.json`을 지우면 아래 로그인 모드로 돌아간다.

**Microsoft 로그인으로 쓰기 (`settings.local.json`)**
- 각 에이전트를 Copilot Studio에서 만들고 **게시**한 뒤, Settings > Advanced > Metadata의 EnvironmentId와 SchemaName을 확인한다.
- 루트에서 `.\LunaFlow-HelpBot\Configure.ps1 -EnvironmentId '<GUID>' -SchemaName '<스키마 이름>' -ReuseAnimationSignIn`처럼 설정 파일을 만든다.
- Entra 앱은 공용 네이티브 클라이언트, 리디렉션 `http://localhost`, 위임 권한 `CopilotStudio.Copilots.Invoke`가 필요하다. 클라이언트 비밀은 쓰지 않는다.
- 첫 요청 때 브라우저에서 Microsoft 계정으로 로그인한다. 로그인 정보는 Windows가 보호하는 MSAL 캐시에 저장된다.

## LunaFlow 도우미 사용법 {#helpbot}
키워드: 도우미, 도움말, 챗봇, 질문, 사용법, 물어보, help, helper, chatbot, assistant, faq

- `도움말 > LunaFlow 도우미`, 상태 줄의 **도우미** 버튼 또는 **Shift+F1**로 연다.
- **Copilot** 모드는 Copilot Studio 도우미 에이전트와 대화한다. 이전 대화를 기억하므로 이어서 질문할 수 있다.
- **내장 도움말** 모드는 로그인 없이 이 사용 설명서에서 가장 관련 있는 주제를 바로 보여 준다. Copilot 연결이 실패해도 내장 답변을 함께 보여 준다.
- 답변 아래의 추천 질문을 누르면 바로 이어서 묻는다. Enter로 보내고 Ctrl+Enter로 줄을 바꾼다.

- 도우미는 사용법만 안내하고 장면을 직접 편집하지 않는다. 동작 편집은 오른쪽 AI 대화, 효과는 VFX AI에 요청한다.

## 문제 해결 {#troubleshooting}
키워드: 문제, 오류, 에러, 안 돼, 안돼, 안됨, 실패, 멈춤, 느려, 안 보, 안보, troubleshoot, error, failed, not working, crash, missing

| 증상 | 해결 |
|---|---|
| `Copilot SDK client/config is missing` | 루트에서 `Build-CopilotClient.ps1`을 실행하고 해당 기능의 `settings.public.json` 또는 `settings.local.json`을 만든다. |
| `인증 안 함 … 다시 게시` | Copilot Studio에서 그 에이전트의 인증을 "인증 안 함"으로 바꾸고 게시한다. |
| `... settings are missing` | 그 기능 폴더의 SETUP.ko.md를 따라 Configure.ps1을 실행한다. 다른 에이전트 설정으로 대체하지 않는다. |
| 403 / 권한 오류 | 에이전트 게시 상태, 사용 권한, `CopilotStudio.Copilots.Invoke` 위임 권한과 조직 동의를 확인한다. |
| AI를 기다리는 동안 편집함 | 동작·효과 편집은 그대로 두고 계획을 현재 장면에 다시 검증해 적용한다. "캐릭터 뼈대가 바뀌어" 또는 "이 계획을 현재 장면에 적용할 수 없습니다"가 보이면 같은 요청을 다시 보낸다. |
| `Operation is not allowed` | 에이전트가 허용되지 않은 명령을 계획했다. 지침을 다시 붙여 넣고 재게시한다. |
| 캐릭터가 안 보임 | F로 선택에 맞추거나 Shift+F로 전체 보기를 한다. |
| AI 동작이 이상함 | Ctrl+Z로 되돌리고 방향·길이·손을 구체적으로 다시 요청한다. 뼈대가 없으면 자동 리깅부터 한다. |
| 모션캡처 설치 실패 | Python 3.11 x64와 `py` 실행기를 설치하고 패널에서 다시 시도한다. |
| 단축키가 안 먹음 | 글자 입력 칸에서 커서를 빼거나 뷰포트를 한 번 클릭한다. 모션캡처 중에는 녹화용 단축키만 쓴다. |

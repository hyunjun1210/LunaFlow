# Third-party components

LunaFlow uses the existing Dear ImGui sources under the repository's MIT license.

- Dear ImGui: https://github.com/ocornut/imgui — `third_party/imgui/LICENSE.txt`.
- Assimp 6.0.4: https://github.com/assimp/assimp/tree/v6.0.4 — BSD-3-Clause and the included component notices in `LICENSE`.
- nlohmann/json 3.12.0: https://github.com/nlohmann/json/tree/v3.12.0 — MIT, `LICENSE.MIT`.
- Assimp's bundled zlib: zlib license, in its `README` and `zlib.h`.

The build copies these license files into the `licenses` directory beside LunaFlow.exe.
Assimp test assets are used from its downloaded `test/models` tree for automated verification.
The built-in Luna rig, cube, and Team C motion example are generated by this project.

- ImGuizmo: https://github.com/CedricGuillemet/ImGuizmo — MIT, `third_party/ImGuizmo/LICENSE`; exact commit in `VERSION.txt`.
- Pretendard 1.3.9: https://github.com/orioncactus/pretendard — SIL Open Font License 1.1, `LunaFlow/Assets/Fonts/OFL.txt`; exact source commit in `VERSION.txt`.

| 기획서 | 현재 구현 |
|---|---|
| A1–A8 | DX11 미리보기·FBX·뼈대·스키닝·보간·직접 편집·Bake 구현 및 테스트 |
| B1 | 메뉴·작업 탭·계층 트리·속성·대화·타임라인·한/영·폰트 |
| B2–B3 | 동작 생성/이름/복제/삭제, 고유 ID와 revision, 길이 변경 |
| B4–B6 | 재생/정지/프레임 이동, 수치·핸들 편집, 키 추가/교체/삭제/시간 이동 |
| B7 | 장면/재질/텍스처/클립/부착/VFX를 포함한 프로젝트 저장·복원, 오류 시 기존 데이터 유지 |
| B8–B9 | AI 대화 UI, 대상/세션/revision 고정, 결과 큐와 공통 편집 명령·충돌 검사 |
| C1–C3 | 실제 AI 계정·제공자 연결과 다른 리그의 리타기팅은 추후 연결 단계. 사용자가 현재는 AI UI만 요청함 |
| C4–C6 | C++의 제공자 중립 요청/상태/결과 큐 구현. 외부 HTTP·유료 생성·자연어 제공자는 비활성/미연결 |
| C7–C8 | Blender 설치에 의존하지 않는 네이티브 FBX 출력으로 구현. 여러 Take·편집 자세·타이밍·텍스처 왕복 테스트 |
| C9 | Unity Generic 가져오기·Animator Controller·프리팹 구성 스크립트. Unity 6 라이브러리로 C# 컴파일 통과 |
| 추가 요청 | 6종 도형, 여러 모델, 손 뼈에 소품 부착, Trail/Sparks/Aura, Unity VFX 메타데이터·런타임 |

Unity Editor 배치 실행은 활성 라이선스가 없어 종료되었다. 엔진 내부의 가져오기·프리팹 재생 검증은 남아 있다.
실제 AI 서비스 연결과 계정 인증은 수행하지 않았고, UI에서도 생성된 것처럼 표시하지 않는다.

루트 UI 스크롤은 한국어/영어, 1000×700·1440×900·1920×1080의 별도 렌더링 회귀 테스트로 확인한다.
작업 모드에 맞는 목록 전환, 목록 탭의 독립적인 선택, 효과 추가 시 VFX 작업 화면 연결도 검사한다.
사용자 화면 조작과 테스트 렌더링은 독립적이며, 테스트는 사용자 설정 파일을 변경하지 않는다.

2026-10-26 검증: Release와 Debug 모두 빌드 성공, CoreAndDX11·UiLayout 검사 통과.
Unity 6000.3.18f1의 실제 어셈블리를 참조한 통합 스크립트 C# 컴파일도 통과했다.
테스트 생성 파일은 정리했으며, [편집기 화면](UI.png)과 [VFX 작업 화면](UI-VFX.png)을 문서에 남겼다.

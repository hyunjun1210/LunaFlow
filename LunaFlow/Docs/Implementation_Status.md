Unity Editor 배치 실행은 활성 라이선스가 없어 종료되었다. 엔진 내부의 가져오기·프리팹 재생 검증은 남아 있다.
2026-10-27에 실제 Copilot Studio 사용자 로그인과 에이전트 응답, 별도 테스트 장면의 편집 계획 적용을 수행했다. 완료 표시는 실제 단계 적용 후 갱신한다.

루트 UI 스크롤은 한국어/영어, 1000×700·1440×900·1920×1080의 별도 렌더링 회귀 테스트로 확인한다.
작업 모드에 맞는 목록 전환, 목록 탭의 독립적인 선택, 효과 추가 시 VFX 작업 화면 연결도 검사한다.
사용자 화면 조작과 테스트 렌더링은 독립적이며, 테스트는 사용자 설정 파일을 변경하지 않는다.

화면 배율 수정 검증 (2026-10-27):

- 패널 너비를 비율로 배치하고, 타임라인 높이를 창 높이·컨트롤 최소 크기로 결정한다.

Ctrl+S 저장창 반복 수정 (2026-10-27):

- 저장·열기 단축키를 키를 누른 첫 순간에만 처리한다. Space 재생 전환과 Ctrl+Enter 생성도 키 반복으로 중복 실행하지 않는다.
- 네이티브 파일 창에서 돌아오면 대기 중인 입력·키·마우스 상태를 정리하여 취소 후 단축키가 남지 않게 한다.
- 실제 프로젝트 저장, Ctrl+S 60프레임 유지 시 중복 저장 없음, 키를 뗀 뒤 재입력, 파일 창의 입력 정리 이후 변경 유지 검사를 추가했다.
- Debug·Release 모두 빌드 성공, 각 구성에서 CoreAndDX11·UiLayout 통과. 사용자 설정 파일은 변경하지 않는다.

Copilot Studio는 [설정 가이드](Copilot_Studio_Setup.ko.md)와 지침·프롬프트·계획 JSON 예시를 준비했다.
VFX와 애니메이션을 모두 대상으로 한다. 최신 SDK의 환경 ID·스키마 검색과 Microsoft 사용자 로그인을 사용한다.
실제 대회 계정으로 대화 응답과 동작 복제 → 길이 1.5초 → 오른손 파티클 계획 적용·프로젝트 저장을 확인했다.
`build/test-output/Copilot-live.lunaflow`는 이 검증 결과이며 사용자 작업 중인 프로젝트를 수정하지 않았다.

체형 보정은 FBX 원본과 대상의 기준 자세, 키 비율, 뼈 길이, 인식된 사람형 체인을 사용한다.
손발 도달 범위, 지면, 양발 지지 시 중심 위치를 보정하며 몸통 근사 형태·관절 접힘 검사 결과를 표시한다.
임의 이름/중복 이름의 뼈에 대한 수동 매핑 편집기, 메시 전체 충돌 해결, 물리 기반 무게중심, 서로 다른 임의 구조의 완전 자동 리타기팅은 구현 범위 밖이다.

사용자 요청 반영과 자동 리깅 (2026-10-27):

- 기본 캐릭터를 제공된 `Chracter Modeling 1.fbx`로 교체했다. 모델링 참고 이미지 평면을 숨기고, 작업자 PC의 PSD 텍스처는 기본 색상으로 대체한다.
- 뼈대가 없는 사람형 메시용 자동 리깅(`Core/AutoRig.cpp`)을 추가했다. 복셀화한 몸에서 다리·목·팔·발 방향을 찾아 26개 사람형 뼈를 맞추고, 몸 안쪽 거리 기반 가중치·이음매 평활화·머리 영역 정리·팔다리 사이 누수 제거를 적용한다. 편집 메뉴, FBX 가져오기 아래 안내 버튼, 시작 시 기본 캐릭터 적용, Undo/Redo를 제공한다.
- 회전 링·시점·속성 드래그의 화면 가장자리 커서 순환, 우클릭 WASD 비행 이동, Ctrl+S 이후 닫기를 수정·검사했다.
- 검 휘두르기의 정면 계산을 왼손 좌표계에 맞게 고치고 예제 리그의 좌우를 바로잡았다. 준비 자세와 몸 앞 베기, 반대 팔 자세를 추가했다.
- AI 응답 대기 중 생각 중 표시·경과 시간·단계 기록과 계획 반영 진행 표시를 추가했다.
- Unity·Blender 방식의 시점 조작·숫자패드 시점·축 기즈모·타임라인 단축키·F1 단축키 목록·편집/보기/도움말 메뉴를 추가하고, 키·장면·효과 편집을 하나의 실행 취소 기록으로 관리한다.
- 새 아이콘을 실행 파일·창·작업 탭 로고에 적용했다.
- 검사: CoreAndDX11(검 휘두르기 회귀, 자동 리깅 상자 인형·거부·검 휘두르기), UiLayout(단축키·기즈모·F1·생각 중 표시·자동 리깅 버튼과 Undo/Redo), DefaultCharacter(실제 FBX 자동 리깅의 관절·대칭·머리 가중치·팔 회전 시 다른 부위 고정).
- Release 빌드 경고 0개, Release·Debug 구성 모두 세 검사 통과.

모션캡처 원버튼 녹화 (2026-10-29):

- 진입: `보기 > 웹캠 모션캡처...`, 타임라인 맨 왼쪽 빨간 녹화(●) 버튼. 패널을 열면 카메라가 바로 켜진다. 런타임이 없으면 **설치하고 카메라 켜기**가 `Setup.ps1`을 앱 안에서 실행(단계 체크리스트·취소·다시 시도)한 뒤 자동으로 켠다.
- 캘리브레이션 버튼을 없애고 기준 자세(15표본, 0.75초 이상)를 자동으로 잡는다. 미리보기에 기준 자세 실루엣, 4단계 체크리스트(카메라·전신·기준 자세·녹화 준비), 전신 위치 안내(`CheckFraming`: 뒤로/앞으로/좌우)를 표시한다.
- 녹화: 버튼 또는 Space. 카운트다운(없음/3/5/10초)은 사람이 화면 안에서 추적될 때만 진행하고, Space/Esc로 취소한다. 자동 정지 5/10/30/60초, 테이크 이름 생략 시 `웹캠 녹화 N`. 뷰포트에 빨간 테두리·`REC` 시간·카운트다운 링을 겹쳐 그린다.
- 정지 즉시 테이크를 새 클립으로 적용(Undo 1단계)하고 키를 자동 정리(`SimplifyTake`, 기본 1°)한 뒤 뷰포트에서 반복 재생한다. 확인 카드: 키 수(원본→정리), 종료 이유, 시작/끝 트림(`TrimTake`), 계속 녹화(Space)·버리기(Del, 클립과 Undo 기록 제거·변경 표시 복원)·완료(Enter, 카메라 끔).
- 캡처 중 단축키는 녹화용으로 바뀌고(F1 목록에 표시) 뷰포트 카메라 이동은 유지한다. 앱/창 닫기 시 카메라를 끄고 테이크를 보존한다.
- 검사: Mocap에 키 정리 오차·상수 트랙 2키·트림 시간 재배치·잘못된 범위 거부·전신 위치 5가지, 확인 흐름(추가·버리기·트림 유지·화면 밖 카운트다운 대기·두 번째 테이크 자동 정지) 추가. UiLayout에서 6가지 상태 화면을 그려 패널이 화면 안에 있고 가로로 잘리지 않는지 검사한다. CTest 7개(CoreAndDX11, UiLayout, DefaultCharacter, VfxAgent, Mocap, MocapTracker, MocapModelSmoke) 통과, Release 빌드 경고 0개.

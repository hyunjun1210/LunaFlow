LunaFlow 데모 실행 방법
========================

1. ZIP 압축을 원하는 폴더에 풉니다.
2. LunaFlow.exe 를 더블클릭합니다.
   - .NET, Visual C++ 런타임 설치나 Microsoft 로그인은 필요 없습니다.
   - Windows 10/11 64비트, DirectX 11 그래픽이 필요합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.

AI 기능 (로그인 없이 바로 사용, 인터넷 필요)
- 동작 AI: 오른쪽 "AI · Copilot Studio" 대화창에 입력합니다.
    예) 오른손으로 검을 휘두르는 동작 만들어 줘
- VFX AI: 상단 VFX 탭 → 오른쪽 아래 VFX AI 에서 Copilot 을 고르고 입력합니다.
    예) 오른손에 파란 불꽃 파티클 붙여 줘
- 사용 도우미 챗봇: Shift+F1, 또는 상태 줄 오른쪽 [도우미] 버튼.
- 회사/학교 방화벽이 Microsoft 서비스를 막으면 AI 가 연결되지 않을 수 있습니다.
  이때도 도우미의 "내장 도움말" 모드와 VFX AI 의 "로컬" 모드는 동작합니다.

기본 조작 (Unity/Blender 스타일)
- 시점 회전: 우클릭 드래그 또는 Alt + 좌클릭 드래그
- 비행 이동: 우클릭을 누른 채 W/A/S/D, Q/E (Shift 빠르게)
- 확대·축소: 마우스 휠
- 도구: W 이동, E 회전, R 크기 / F 선택 대상 맞추기
- Space 재생/정지, K 키 추가, Ctrl+Z 되돌리기, Ctrl+S 저장
- 전체 단축키: F1

웹캠 모션캡처 (선택)
- Python 3.11 (64비트)이 설치되어 있어야 합니다.
- 타임라인 왼쪽 빨간 녹화(●) 버튼 → 처음 한 번 "설치하고 카메라 켜기" → 녹화(Space).

Unity 로 가져가기
- 파일 → 내보내기 → Unity 패키지 로 Unity 프로젝트의 Assets/LunaFlow 폴더에 저장합니다.
- 자세한 방법은 도우미 챗봇에 "Unity로 가져가는 법"을 물어보세요.

문제 해결
- AI 오류에 "인증 안 함 … 다시 게시"가 보이면 제작자에게 알려 주세요(서버 설정 문제).
- 화면이 뜨지 않으면 그래픽 드라이버를 최신으로 업데이트하세요.

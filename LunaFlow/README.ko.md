# LunaFlow — Motion & VFX Studio

Windows / DirectX 11 기반 캐릭터 애니메이션 편집기.

## 실행과 프로젝트

- **실행:** 최상위 `Start-LunaFlow.cmd` 더블클릭
- **Visual Studio:** 프로젝트 루트의 `Open-LunaFlow.cmd` 실행 (솔루션을 현재 경로로 다시 구성한 뒤 열기)
- **실행 파일:** `build/Release/LunaFlow.exe`
- **전체 프로젝트:** `파일 > 프로젝트 저장` 또는 `Ctrl+S`
- **복원:** `파일 > 프로젝트 열기` 또는 `Ctrl+O`
- **아이콘:** 실행 파일·창 제목 표시줄·작업 탭 왼쪽 로고에 LunaFlow 아이콘을 사용한다. 원본과 생성 스크립트는 `Assets/Icon`에 있다.

시작할 때 사용자가 제공한 `Chracter Modeling 1.fbx`의 사본을 기본 캐릭터로 연다.
사본은 소스의 `Assets/Characters/DefaultCharacter.fbx`, 배포 폴더의 `Characters/DefaultCharacter.fbx`에 있다.
이 파일은 뼈대가 없는 모델링 단계 모델이므로 열 때 [자동 리깅](#자동-리깅)을 적용해 바로 동작을 만들 수 있게 한다.
모델링 참고용 이미지 평면은 숨기고, 작업자 PC의 PSD처럼 찾을 수 없는 텍스처는 기본 색상으로 표시한다.
기본 파일이 없거나 손상되면 안내와 함께 내장 예제 장면을 연다.

프로젝트에는 장면의 메시·기본 재질·텍스처·뼈대·부착 관계·모든 동작·VFX·현재 선택과 카메라를 저장한다.
새 장면이나 종료 시 저장하지 않은 작업이 있으면 저장·폐기·취소를 선택한다.
현재 동작만 따로 저장하는 JSON과 전체 프로젝트 저장은 구분된다.

## 작업 공간

상단 `+`는 장면에 오브젝트나 VFX를 추가한다.
파일·편집·보기·설정 메뉴 아래에 애니메이션·장면·VFX 작업 탭이 있다.
작업 탭을 전환하면 애니메이션은 동작 목록, 장면은 계층, VFX는 효과 목록과 효과 속성이 열린다.
왼쪽의 목록 탭은 작업 탭과 별도로 전환할 수 있다.

- **왼쪽:** 화살표로 펼치고 접는 계층, 동작 관리, 자산 정보, 효과 목록
- **가운데:** 3D 뷰포트와 이동·회전·크기 조절 핸들, 타임라인
- **오른쪽:** 선택 대상의 속성, AI 대화 UI
- **하단:** 저장 상태와 실제 측정 FPS

바깥 작업 화면은 고정되어 있다. 계층·속성·대화 기록처럼 필요한 패널 안에서만 스크롤된다.
폰트는 한국어·영문용 Pretendard Regular/SemiBold를 함께 제공한다.

장면 탭에서 표면을 선택하면 오브젝트 단위로 조작한다.
장면의 배치는 모든 동작에 유지되고, 애니메이션 탭의 뼈 조작은 선택한 동작에 키로 기록된다.
애니메이션 탭에서는 뼈를 직접 선택하고 현재 시각에 키를 기록한다.
변환 핸들의 로컬/월드 기준도 전환할 수 있다.

## 캐릭터와 소품

왼쪽 위 **FBX 가져오기** 또는 `파일 > FBX 가져오기`에서 다음을 선택한다.

- **캐릭터 열기:** 현재 장면을 저장할지 확인한 뒤 캐릭터와 포함된 동작을 연다.
- **현재 장면에 모델 추가:** 기존 캐릭터를 유지하고 소품/모델을 추가한다.
- **동작만 가져오기 · 체형 보정:** FBX의 동작을 선택하여 현재 캐릭터에 맞춘 새 클립을 만든다.

체형 보정은 키에 따른 이동·보폭 배율, 대상 뼈 길이와 기준 회전, 손발 IK, 양발 지지 시 중심 위치 안정화를 사용한다.
동작 이름을 선택하고 보정 옵션 및 15/30/60 FPS를 설정한다. 결과는 원본 동작을 유지한 새 클립이며 Ctrl+Z로 되돌린다.
동작 목록 아래에서 **현재 동작 포즈 검사**와 보정 결과를 볼 수 있다.
뼈 매칭은 전체 경로 또는 정규화된 이름을 사용하며 Mixamo 네임스페이스와 일부 사람형 이름 변형을 처리한다.
이름이 중복되거나 인식할 수 없는 뼈는 임의로 연결하지 않는다. 매칭되지 않은 뼈는 기준 자세를 유지하며 목록에 표시한다.
손발 IK는 인식된 UpperArm/ForeArm/Hand, UpperLeg/LowerLeg/Foot 체인에 적용한다.
지면·몸통·관절 접힘 검사는 뼈 위치와 몸통 근사 형태를 사용한다. 메시 전체의 충돌 검사나 물리 시뮬레이션은 아니다.

1. `파일 > 캐릭터 불러오기`로 캐릭터 FBX를 연다. 뼈대가 없으면 [자동 리깅](#자동-리깅)을 적용한다.
2. `+ > 모델 / 소품 가져오기`로 검 등 다른 모델을 같은 장면에 추가한다.
3. 계층에서 검의 최상위 오브젝트를 선택한다.
4. 속성의 **오브젝트 부착**에서 캐릭터의 RightHand 같은 뼈를 고른다.
5. `선택한 뼈에 부착`을 누르고, 핸들이나 수치로 검의 방향·위치·크기를 조정한다.
6. 손·팔에 키를 넣어 휘두르는 동작을 만든다. 검은 손 뼈를 따라 움직인다.

FBX·glTF·GLB·OBJ를 읽는다. 기본 색상과 diffuse/base-color 텍스처, 스킨 가중치를 지원한다.
FBX 단위와 축은 내부의 미터·왼손 좌표계·Y-up으로 변환한다.
파일의 잘못된 단위 정보를 보정할 추가 배율은 환경 설정에서 지정한다.
FBX 내보내기는 노드 이름이 서로 달라야 한다. 추가한 소품의 충돌 이름은 자동으로 구분한다.

`+`에서 큐브·구·원기둥·원뿔·평면·토러스를 여러 개 추가할 수 있다.

### 자동 리깅

뼈대가 없는 사람형 메시를 열면 왼쪽 **FBX 가져오기** 버튼 아래에 안내와 **자동 리깅** 버튼이 나타난다.
이 버튼이나 `편집 > 캐릭터 자동 리깅`을 누르면 메시 형태를 분석해 사람형 뼈대와 스킨 가중치를 만든다.
기본 캐릭터는 시작할 때 자동으로 적용한다. 결과는 Ctrl+Z로 되돌리고 Ctrl+Y로 다시 적용한다.

- **뼈대:** Hips·Spine·Chest·Neck·Head, 양쪽 Shoulder·UpperArm·ForeArm·Hand, UpperLeg·LowerLeg·Foot·Toes와 끝점을 합친 26개 뼈. Unity 사람형 이름을 사용하므로 AI 동작 명령·FBX 동작의 체형 보정·FBX/Unity 내보내기에 그대로 쓴다.
- **위치 찾기:** 메시를 복셀로 바꿔 다리 분리 높이·목·어깨에서 갈라지는 팔·팔꿈치·손목·무릎·발을 찾는다. 좌우가 대칭인 몸에는 대칭인 뼈대를 만든다.
- **정면:** 발끝이 향하는 쪽을 정면으로 정하므로 모델이 어느 방향을 보고 있어도 된다. 다리가 가려지는 긴 옷·로브는 어깨 폭과 옷자락 밖으로 나온 발을 사용한다.
- **가중치:** 뼈에서 몸 안쪽을 따라 잰 거리로 계산하고 이음매를 부드럽게 한다. 목 위의 머리카락·모자·후드는 목·머리 뼈에 연결하고, 손이 옷자락에 닿아 있어도 팔을 움직일 때 다리 쪽이 끌려가지 않게 정리한다.
- **자세:** 서 있는 T·A 자세가 가장 정확하다. 팔을 내린 I 자세나 몸에 붙은 팔은 신체 비율과 어깨–손끝 직선으로 관절을 정하고 정보 탭에 안내를 남긴다. 몸에 붙은 겨드랑이 부분은 팔을 크게 들면 늘어날 수 있다.
- **거부:** 분리된 다리·목·몸에서 갈라지는 양팔 중 두 가지 이상이 보이지 않는 메시(상자·기둥·소품)나 누워 있는 모델은 바꾸지 않고 이유를 표시한다. 이미 스킨이나 사람형 뼈대가 있는 모델에는 자동 리깅을 표시하지 않는다.

## 동작과 키프레임

왼쪽 **동작** 탭에서 빈 동작 생성·선택·이름 변경·복제·삭제·길이 변경을 한다.
복제는 독립적인 키와 새 ID를 가진다. 길이 변경은 전체 키 시간을 함께 변경한다.

타임라인에서 원하는 시각으로 이동하고 뼈를 선택해 변환하면 그 시각에 키가 생긴다.
재생·일시 정지와 처음/이전/다음/끝 이동은 텍스트 대신 아이콘을 사용한다.
키 다이아몬드를 선택하고 `선택 키 편집` 또는 더블클릭으로 키 시간을 바꾸거나 삭제한다.
같은 시간으로 옮기면 기존 키를 교체한다.
처음으로 이동, 한 프레임 앞/뒤, 반복, 재생·정지를 제공한다.

## VFX

상단 **VFX** 작업 탭은 Unity·Blender처럼 왼쪽 목록, 가운데 뷰포트, 오른쪽 속성과 AI로 나뉜다.

- **효과 목록(왼쪽):** 체크박스로 켜고 끄며, 더블클릭하면 뷰포트가 그 효과로 이동한다. 우클릭 메뉴나 위쪽 버튼으로 복제·삭제한다.
- **새 효과 갤러리(왼쪽 아래):** 파티클·불꽃·연기·마법·눈·비·폭발·칼 궤적·스파크·오라를 한 번 눌러 `부착 위치`에 표시된 뼈에 추가한다. `+ > 파티클 시스템`도 사용할 수 있다.
- **효과 속성(오른쪽):** Unity Inspector처럼 활성화·재생·처음부터 → 부착·재생 구간 → 기본 → 방출 → 모양 → 추가 속도 → 시간에 따른 색상·크기(그라데이션 미리보기) → 렌더러 순서로 접고 편다. 부착 뼈는 검색해서 고르고, 색상은 견본을 눌러 선택한다. 맨 아래에서 복제·삭제한다.
- **VFX AI(오른쪽 아래):** 하나의 대화창에서 `Copilot`(로그인 AI)과 `로컬`(키워드 규칙)을 전환한다. 예시 버튼을 누르면 입력이 채워지고 Ctrl+Enter로 보낸다. 로컬 결과와 오류 안내도 같은 대화에 표시한다. 머리글의 ▼로 숨기면 속성이 열 전체를 쓰고, 아래 `VFX AI 열기`로 다시 연다.

예: `파란 마법 파티클, 초당 80개, 수명 1.5초, 크기 0.12, 반경 0.3`

**로컬** 모드는 **한국어/영어 키워드와 수치를 해석하는 로컬 규칙 방식**이며 외부 AI를 호출하지 않는다. 생성한 효과는 Ctrl+Z로 되돌린다.
불꽃/fire, 연기/smoke, 마법/magic, 눈송이/snow, 빗방울/rain, 폭발/explosion, 파티클/particle을 지원한다.
색상, 느리게/빠르게, 반복/한 번, 구형/원뿔/상자/고리, 월드와 `초당`, `수명`, `속도`, `크기`, `반경`, `퍼짐`, `방출`, `한번에` 뒤의 수치를 지원한다.
영어 수치는 `rate 80, lifetime 2, speed 1.5, size 0.1, radius 0.3, angle 30, duration 2, burst 150` 형식이다.
지원하지 않는 설명이나 허용 범위를 벗어난 수치는 오류를 표시하며 기존 효과를 바꾸지 않는다.

**기본 설정:** 방출 주기·반복·수명·시작 속도·무작위 비율·중력·시드·최대 입자 수.
**방출/모양:** 초당 입자 수·Burst와 원뿔/구/상자/고리 모양.
**시간에 따른 변화:** 시작/끝 크기와 색상·투명도를 선형 보간한다. 가산 합성 또는 알파 합성을 고를 수 있다.
복제·삭제·활성화와 Ctrl+Z 되돌리기를 제공한다.

효과는 선택한 동작과 뼈에 연결되고 동작의 시간 범위 안에서 재생된다.
방출 주기가 끝나면 남은 입자는 수명 동안 유지되며, 효과 종료 시각에서는 전체가 종료된다.
타임라인을 이동하면 같은 시드·시간에서 같은 입자 상태가 재현된다.
월드 공간은 방출 당시의 뼈 위치를 60Hz로 샘플링한다. 미리보기는 시스템당 최대 4,096개, 장면 전체 최대 16,384개의 입자를 그린다.

칼 궤적·스파크·오라도 갤러리나 `+` 메뉴에서 추가한다.
상단 VFX를 선택하면 왼쪽 **효과 목록**과 오른쪽 **효과 속성**이 열린다.
효과를 추가하면 VFX 작업 탭으로 이동한다. 효과를 선택하면 연결된 동작도 함께 선택한다.
효과 속성과 뷰포트 핸들에서 다음을 바꿀 수 있다.

- 부착할 뼈 또는 소품
- 위치·회전·크기 핸들
- 색상·강도·효과 크기
- 선택 동작의 효과 시작·종료 시각

칼 궤적은 부착점에서 로컬 +Y 방향으로 뻗는 날의 움직임을 기록한다.
검의 원점과 날 방향에 맞춰 효과의 오프셋·방향·크기를 조절한다.
효과는 전체 프로젝트에 저장된다.

## Copilot Studio에서 애니메이션·VFX 편집

오른쪽 **AI · Copilot Studio** 대화에 현재 동작이나 효과의 생성·수정을 요청한다.
첫 요청은 브라우저에서 CNE-AI의 에이전트를 사용할 Microsoft 계정으로 로그인한다.
로그인 정보는 Windows에서 보호되는 MSAL 캐시를 사용한다. 클라이언트 비밀은 사용하지 않는다.

예: `선택한 동작을 복제해서 1.5초로 줄이고, 복제한 동작의 오른손에 파란 불꽃을 붙여 재생해 줘.`

응답을 기다리는 동안 대화에 응답 자리가 먼저 생기고, 반짝이는 **생각 중…** 글자·경과 시간·현재 단계(연결, 계획 생성 등)를 표시한다.
응답이 오면 **N초 동안 생각함** 제목 아래에 단계 기록을 접어 둔다. 계획을 반영하는 동안에는 `편집 적용 중 k/N`, 진행 막대, 단계별 완료·실패·중지 아이콘을 보여 준다.
중지·오류·완료 시 표시는 바로 사라진다.

검 휘두르기는 팔만 돌리지 않고 전신으로 만든다. 검 쪽 발을 앞으로 내딛으며 엉덩이를 낮추고, 골반·척추·가슴을 뒤로 감았다가 풀면서 몸 앞 아래로 벤다.
뒷발은 IK로 바닥에 고정하고, 머리는 목표를 바라보도록 반대로 돌리며, 쇄골·반대 팔이 균형을 잡는다. 동작은 30fps로 조밀하게 키를 만든다.
방향은 기준 자세의 엉덩이→머리 방향과 좌우 팔 위치로 계산한 캐릭터의 실제 정면을 따르므로, 손은 항상 몸 앞을 지난다.
뼈대가 없는 캐릭터에 사람형 동작을 요청하면 `편집 > 캐릭터 자동 리깅`을 먼저 안내한다.

현재 뼈·선택한 동작의 키·효과·좌표계·허용 명령을 에이전트에 전달하고, 완성된 JSON 계획을 검증한 뒤 화면에서 단계별로 적용한다.
단계 목록의 완료 표시는 실제 편집이 반영된 뒤 갱신한다. 기다리는 동안의 LLM 응답과 로컬 단계 실행은 구분한다.
새 동작, 복제·이름·길이·반복, 뼈 키/회전 차이 편집, 파티클 생성·수정·부착, 결과 재생을 지원한다.
완성된 계획 전체를 미리 검증하므로 잘못된 뒤쪽 단계가 있으면 앞쪽 단계도 적용하지 않는다.
요청 후 사용자가 뼈대·동작·효과를 수정하면 오래된 결과와 나머지 단계의 적용을 중단한다.
**작업 중지**로 취소할 수 있고, 이미 적용한 AI 작업은 **Ctrl+Z 한 번**으로 함께 되돌린다.

설정은 프로젝트의 `agent_service/copilot_client/settings.local.json`이다.
VFX 탭의 대화는 파티클 명령만 허용하는 **전용 VFX 에이전트**를 사용하며 설정은 `LunaFlow-VFXAgent/settings.local.json`이다.
VFX 설정이 없으면 오류를 표시하고 애니메이션 에이전트로 대체하지 않는다. 생성·게시·연결은 [VFX 에이전트 안내](../LunaFlow-VFXAgent/README.ko.md)를 따른다.
두 대화는 기록이 분리되어 있고, 한 장면을 동시에 수정하지 않도록 한 번에 한 AI 작업만 실행한다.
CMake에서 .NET SDK가 있으면 연결 프로그램을 함께 빌드하며, 별도로 `Build-CopilotClient.ps1`로 빌드할 수도 있다.
이 PC에서는 실제 SDK 대화 및 동작 복제·속도 변경·오른손 파티클 계획 적용을 검증했다.
외부 모션 생성 서비스나 임의 리그의 자연스러운 전신 동작 품질까지 보장하는 기능은 아니다.

## 웹캠 모션캡처

`보기 > 웹캠 모션캡처...` 또는 타임라인 맨 왼쪽의 빨간 **녹화(●)** 버튼으로 웹캠 전신 동작을 **새 동작 클립**으로 녹화한다.
기본 캐릭터(자동 리깅)와 리깅 예제 캐릭터를 바로 지원하며, 좌우는 사용자의 해부학적 좌우를 따른다(영상 좌우 반전 없음).

1. 패널을 열면 카메라가 바로 켜진다. 처음이면 **설치하고 카메라 켜기** 한 번으로 Python 전용 환경과 MediaPipe 모델이 앱 안에서 설치된다.
2. 전신이 보이게 서서 팔을 내리고 잠깐 멈추면 기준 자세가 **자동으로** 잡힌다(패널 체크리스트와 뷰포트 안내 표시).
3. **녹화** 또는 Space → 카운트다운(기본 3초) → 녹화(뷰포트 빨간 테두리·REC 시간) → **정지** 또는 Space.
4. 테이크는 즉시 캐릭터에 적용되어 반복 재생된다. **계속 녹화(Space) / 버리기(Del) / 완료(Enter)**, 시작·끝 트림을 고른다.
5. 키프레임은 허용 오차 1°로 자동 정리된다. 잘못 잡힌 키는 타임라인에서 지우면 되고, 테이크마다 Ctrl+Z, 저장은 Ctrl+S.

카메라가 켜진 동안 메뉴·편집·타임라인·AI 작업은 잠기고, 단축키는 녹화용(Space·Esc·Enter·Del)으로 바뀌며 뷰포트 카메라 이동은 그대로 쓸 수 있다.
영상은 저장하거나 외부로 보내지 않는다. 자세한 조건·제한은 [모션캡처 안내](../LunaFlow-Mocap/README.ko.md)에 있다.

## 내보내기와 Unity

`파일 > 내보내기`에서 다음을 선택한다.

- **캐릭터 + 모든 동작 FBX:** 메시·기본 재질·텍스처·스킨·계층과 편집한 모든 동작을 여러 Take로 출력
- **Unity 패키지:** FBX + 효과/동작 메타데이터 + Unity Runtime/Editor 스크립트
- **최종 자세 JSON:** 다른 변환기에 전달할 전체 로컬 TRS 표본
- **뼈대 JSON / 미리보기 PNG**

Unity 패키지는 Unity 프로젝트의 **Assets/LunaFlow** 폴더에 `Scene.lunaflow.json`으로 저장한다.
다른 곳에 내보냈다면 생성한 폴더 전체를 Assets/LunaFlow로 가져온다.
스크립트는 Generic 리그의 여러 동작, Animator Controller, 프리팹을 구성한다.
검의 부착은 FBX 계층으로, VFX는 별도 JSON으로 전달한다. 새 파티클은 Unity의 기본 `ParticleSystem` 모듈로, 기존 효과는 런타임 메시·라인으로 구성하므로 VFX Graph 패키지는 필요 없다.
자세한 설명은 [Unity 안내](../unity_tools/README.ko.md)에 있다.

내보내기 없이 저장한 `.lunaflow` 프로젝트 파일을 Unity에서 직접 가져오려면 [LunaFlow-Unity 패키지](../LunaFlow-Unity/README.md)를 사용한다.
Unity Package Manager의 `Add package from disk`로 `LunaFlow-Unity/package.json`을 선택하면 모델·뼈대·동작·VFX가 하위 에셋으로 만들어진다.
기존 내보내기(FBX + `.lunaflow.json`)와 확장자·namespace가 달라 함께 사용할 수 있다.

## 언어와 FPS

창 크기가 바뀌어도 왼쪽 목록·미리보기·오른쪽 속성의 너비 비율을 유지한다.
타임라인은 재생 컨트롤과 프레임 격자가 들어갈 최소 높이를 확보하고, 폭이 부족하면 컨트롤을 다음 줄로 배치한다.
Windows 화면 배율에 맞춰 재생 버튼·아이콘·패널 여백·저장 확인창 크기를 함께 조정한다.
배율이 다른 모니터로 창을 옮기면 UI 배율을 다시 계산한다.
저장 확인창 버튼은 글자 길이에 맞춰 폭을 확보하며, 화면이 좁으면 세로로 배치한다.

`설정 > 환경 설정`에서 한국어/English를 고른다.
화면 성능과 내보내기 샘플링은 별도 설정이다.

- **화면 FPS:** VSync와 60·120·144·165·240·제한 없음 중 상한 설정. 실제 FPS를 상태 줄에 표시
- **타임라인 격자:** 24·30·60·120·240FPS
- **내보내기 샘플링:** 24·30·60·120·240FPS, 기본 60

30FPS는 과거 기본 Bake 간격이었다. 화면 재생을 30FPS로 제한한 것이 아니다.
VSync를 켜면 모니터 주사율의 영향을 받는다.

## AI 대화

오른쪽 대화는 Microsoft 계정으로 로그인한 **Copilot Studio** 에이전트에 실제로 연결한다.
자세한 연결과 지원 편집은 위의 [Copilot Studio 안내](#copilot-studio에서-애니메이션vfx-편집)를 따른다.

`AgentBridge/AgentSession`은 요청 시 프로젝트 세션·클립 ID·revision·뼈대 서명을 고정한다.
작업 스레드는 JSON 결과만 큐에 넣고, 편집 데이터 반영은 메인 스레드에서 수행한다.
늦은 결과·다른 프로젝트·수정된 클립·바뀐 뼈대·중복 완료 응답을 검증한다.
계획 생성과 편집 반영을 구분하고, 실제 적용된 단계만 완료로 표시한다.
외부 전신 모션 생성 API와 임의 구조의 리그에 대한 자동 동작 생성은 아직 제공하지 않는다.

문장이 요청 JSON → 편집 계획 JSON → 검증 → 단계 실행으로 바뀌는 과정, 명령별 인자, 예시와 오류는
[문장 → JSON 변환 구조](Docs/Sentence_to_JSON.ko.md)에 정리했다.

## LunaFlow 도우미

**Shift+F1**, 상태 줄 오른쪽 **도우미** 버튼, 또는 `도움말 > LunaFlow 도우미`로 사용법을 묻는 대화 창을 연다.

- **내장 도움말:** 로그인·인터넷 없이 바로 쓸 수 있다. 질문과 가장 관련 있는 사용 설명서 주제(카메라, 자동 리깅, 검 휘두르기, VFX, 모션캡처, Unity 등 20개)를 즉시 보여 준다.
- **Copilot:** 전용 Copilot Studio 도우미 에이전트와 대화한다. 질문마다 관련 설명서 발췌와 현재 편집기 상태 요약(작업 탭, 파일 이름, 뼈·동작·효과 수, 저장 여부 등)을 함께 보내므로
  "지금 뭘 먼저 해야 해?" 같은 질문에도 상황에 맞게 답한다. 같은 대화를 이어 가며, 실패하면 내장 답변을 함께 보여 준다.
- 답을 기다리는 동안 **생각 중…**과 경과 시간을 표시하고 **중지**로 취소한다. 답 아래 추천 질문을 누르면 이어서 묻는다.
- Enter로 보내고 Ctrl+Enter로 줄을 바꾼다. **새 대화**는 기록을 지우고 새로 시작한다.
- 도우미는 장면을 편집하지 않는다. 동작은 AI 대화, 효과는 VFX AI에 보낼 문장을 제안한다. 애니메이션 AI가 작업 중이어도 질문할 수 있다.

Copilot 모드는 [도우미 에이전트 설정](../LunaFlow-HelpBot/SETUP.ko.md)대로 에이전트를 만들고 `LunaFlow-HelpBot\Configure.ps1`을 한 번 실행하면 켜진다.
설명서 원본은 `LunaFlow-HelpBot/Knowledge/LunaFlow_Help.ko.md`이며, 같은 파일을 Copilot Studio 지식으로도 올린다. 구조는 [도우미 안내](../LunaFlow-HelpBot/README.ko.md)에 있다.

## 개발과 검증

Visual Studio의 C++ 데스크톱 개발 도구, Windows SDK, CMake 도구가 필요하다.
C++17을 사용하며 Assimp와 JSON 라이브러리는 초기 구성에서 고정 버전·해시로 가져온다.

```powershell
.\Build-LunaFlow.ps1 -Configuration Release -Test
.\Build-LunaFlow.ps1 -Run
```

소스는 `LunaFlow`, 외부 라이브러리는 `third_party`, 생성 파일은 `build`에 있다.
기존 ImGui 예제·개발 자료는 `.archive`에 보관했고 실행에 사용하지 않는다.

데이터/그래픽 테스트는 보간·계층·키 편집·revision·프로젝트 복원·6종 도형·피킹·뼈 조작·검 부착·VFX·Unity 패키지·FBX 왕복을 확인한다.
검 휘두르기는 Mixamo 이름의 T자세 리그와 자동 리깅한 기본 캐릭터에서 손이 항상 몸 앞을 지나는지, 앞발 내딛기·엉덩이 낮추기·어깨 감기/풀기·뒷발 고정·발이 바닥 아래로 내려가지 않는지 검사한다.
자동 리깅은 T·A·I 자세, 여러 방향으로 돌린 인형, 로브 형태의 관절 위치·정면·기준 자세 유지와 팔을 돌릴 때 머리·다리·반대 팔이 움직이지 않는지, 상자·기둥 거부를 검사한다.
기본 캐릭터 테스트(`LunaFlowAssetTests`)는 실제 FBX의 26개 뼈, 관절 위치·좌우 대칭, 머리 가중치, 팔 회전 시 다른 부위 고정을 확인한다.
별도 UI 테스트는 실제 앱 코드를 화면에 창을 띄우지 않고 렌더링해 한국어/영어·여러 창 크기·루트 스크롤 회귀를 검사한다.
단축키·시점 기즈모·F1 단축키 목록·회전 링의 커서 순환·우클릭 비행 이동·Ctrl+S 이후 닫기·AI 생각 중 표시·자동 리깅 버튼과 Undo/Redo, VFX 갤러리·로컬 생성 대화·VFX AI 숨기기/다시 열기도 UI 테스트에 포함한다.
VFX 에이전트 테스트(`LunaFlow.VfxAgent`)는 허용 명령 제한, 생성/수정, 충돌/취소, 대화 분리, Undo를 검사한다.
모션캡처 테스트(`LunaFlow.Mocap`, `LunaFlow.MocapTracker`)는 패킷·캘리브레이션·좌우/깊이 회전·추적 손실·30FPS 녹화, 가상 worker 프로세스,
자동 리깅한 기본 캐릭터에서 오른팔이 캐릭터 오른쪽으로 들리는지와 녹화 → 저장 → 다시 열기를 검사한다.
도우미 테스트(`LunaFlow.HelpBot`)는 설명서 파싱·질문 순위·요청 크기 제한·Markdown 표시 변환, 100–200% 배율과 한국어/영어에서 창 배치,
가상 Copilot 응답(진행 단계·추천 질문·대화 이어가기·실패 시 내장 답변·중지·Shift+F1)을 로그인 없이 검사한다.
원버튼 녹화 흐름(화면 밖이면 기다리는 카운트다운, 자동 정지, 즉시 적용·계속 녹화·버리기·트림)과 키 자동 정리 오차·전신 위치 안내도 검사하고,
UI 테스트는 캘리브레이션·준비·카운트다운·녹화·확인·꺼짐 화면이 잘리지 않는지 확인한다. 실제 웹캠과 사람은 사용하지 않는다.
`LunaFlow-Unity\Tools~\ContractTests.csproj`는 Unity 없이 `.lunaflow` 파일 계약을 검사한다.
Unity 6의 설치된 라이브러리를 참조한 C# 컴파일은 확인했다.
현재 Unity 라이선스가 활성화되어 있지 않아 Unity Editor의 실제 가져오기·Play 모드 검증은 완료하지 못했다.

현재 재질은 기본 색상·텍스처·조명이다. 전체 PBR, 모프 타깃, 일반적인 DCC 제약조건 편집기는 지원하지 않는다.
자동 리깅은 서 있는 사람형 캐릭터용이다. 손가락·얼굴·옷자락 뼈나 사족 보행 등 다른 구조의 뼈대는 만들지 않는다.
FBX 동작 가져오기의 이름 기반 매칭·체형 보정·손발 IK는 지원한다. 임의 뼈 이름의 수동 매핑, 메시 전체 충돌 해결, 서로 다른 임의 리그 사이의 완전 자동 리타기팅은 지원하지 않는다.
상용 도구의 작업 흐름을 기준으로 개선한 구현이며, Blender·Unity 전체 기능과 동등한 완성도를 의미하지 않는다.
